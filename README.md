# KidSmart AI Secure

Plateforme éducative intelligente et sécurisée pour les enfants de 5 à 12 ans.

## Objectifs
- Apprentissage interactif
- Protection des données personnelles
- Cybersécurité dès la conception
- Supervision et détection SOC
- Préparation aux compétences RNCP niveau 7

## Orientation professionnelle
Analyste cybersécurité / SOC

## Environnements
- Frontend : React / TypeScript
- Backend : Python / FastAPI
- Base de données : PostgreSQL
- Conteneurs : Docker
- Supervision : Wazuh

## Sécurité
Tous les laboratoires sont réalisés sur des environnements de test autorisés.
